## Methodology
These results were generated by running `run_real.py` which:
1. Loads the GPT-2 model from HuggingFace
2. Performs a forward pass on test text
3. Measures time, perplexity, and memory usage
4. Runs 5 iterations for timing stability

Baseline standard attention used for comparison.
